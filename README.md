# Mahmoud Mosad — Developer Portfolio

A responsive, brutalist-inspired personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Before publishing
1. Replace both instances of `YOUR_EMAIL@example.com` in `index.html` with your public contact email.
2. Verify every project URL and profile link.
3. Add a PDF CV link if you want the downloadable-resume feature.
4. Update the year in the footer when needed.
5. Review the skills section and only keep skills you are comfortable discussing.

## Deploy to Vercel (free)
1. Create a GitHub repository and upload these files to its root.
2. Sign in to [Vercel](https://vercel.com/) with GitHub.
3. Select **Add New → Project**, then import the repository.
4. Keep Framework Preset as **Other**. No build command or output directory is needed.
5. Click **Deploy**. Vercel will provide a free `*.vercel.app` address.

## Notes
- No framework or build step is required.
- The reveal effects respect the visitor's reduced-motion preference.
- Google Fonts are loaded remotely; use local font files if you need fully offline rendering.
