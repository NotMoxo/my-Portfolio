## Overview

This is my personal developer portfolio, built to bring together my work, skills, and progress as a Computer Science student.

The website follows a brutalist-inspired visual style, combining bold typography, high-contrast colors, sharp edges, and interactive elements to create a distinctive experience.

**[Explore the live website →](https://portfolio-steel-six-16.vercel.app/)**

## Features

- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Custom Visual Identity** — Bold typography, minimal layouts, and lime accents.
- **Scroll Reveal Animations** — Elements animate into view using Intersection Observer.
- **Interactive Hero** — Pointer-based 3D tilt effect.
- **Mobile Navigation** — Responsive navigation menu.
- **Projects Showcase** — Highlights selected development projects.
- **Competitive Programming** — Links to Codeforces and LeetCode profiles.
- **CV Download** — Direct access to my resume.
- **Accessibility** — Respects reduced-motion preferences.

## Getting Started

Run the project locally without installing dependencies.

**1. Clone the repository**

```bash
git clone https://github.com/NotMoxo/my-Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd my-Portfolio
```

**3. Launch the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
